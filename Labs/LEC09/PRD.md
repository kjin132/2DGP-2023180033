# 애니메이션 뷰어 PRD

## 1. 목표

`sonic-sprite.png`에 포함된 모든 동작 애니메이션을 분석하고, 동작별 프레임을 순서대로 재생하는 학습용 애니메이션 뷰어를 제작한다.

사용자는 프로그램을 실행한 뒤 별도의 설정 없이 화면에서 캐릭터의 모든 동작을 확인할 수 있어야 한다. 하나의 동작은 정해진 횟수만큼 반복한 뒤 잠시 멈추고, 다음 동작으로 자연스럽게 이어져야 한다.

## 2. 범위

### 포함할 기능

- Python과 `pico2d`를 사용한다.
- 실행 소스는 `sonic_animation_viewer.py` 단일 파일로 작성한다.
- `sonic-sprite.png` 파일을 프로그램 시작 시 한 번만 읽는다.
- 스프라이트 시트의 크기와 프레임 배치를 분석해 애니메이션 데이터를 정의한다.
- 각 동작의 프레임을 지정된 순서로 화면에 표시한다.
- 원본 프레임을 `SCALE = 8`로 확대해 출력한다.
- 동작마다 5회 반복하고, 반복이 끝나면 1초간 대기한다.
- 모든 동작을 재생한 뒤 첫 동작으로 돌아가 무한 반복한다.
- 창 닫기 요청과 `ESC` 키 입력을 처리하고 이미지와 창 자원을 정리한다.

### 제외할 기능

- 사용자 입력을 통한 동작 선택
- 애니메이션 편집 및 프레임 추가 기능
- 파일 선택 창과 스프라이트 이미지 교체 기능
- 재생 속도 조절 UI
- 동작 목록이나 현재 프레임을 표시하는 별도 편집 패널

## 3. 스프라이트 동작 목록

스프라이트 시트는 위에서부터 10개의 동작 행으로 분석한다. 코드에서는 이미지 위쪽 기준의 `(left, top, width, height, pivot_x, pivot_y)`를 사용하고, `draw_frame()`에서 `bottom = SPRITE_HEIGHT - top - height`로 pico2d 좌표로 변환한다. 프레임 수의 합은 76장이어야 한다.

|           번호 | 동작 이름                 | 시트 행 |    프레임 수 | 이동 여부 |
| -------------: | ------------------------- | ------: | -----------: | --------- |
|              1 | 대기 (`idle`)       |       1 |           11 | 아니오    |
|              2 | 걷기 (`walk`)       |       2 |           12 | 예        |
|              3 | 달리기 (`run`)      |       3 |            6 | 예        |
|              4 | 구르기 (`roll`)     |       4 |            9 | 예        |
|              5 | 공 (`ball`)         |       5 |            6 | 예        |
|              6 | 대시 (`dash`)       |       6 |            6 | 예        |
|              7 | 출발 (`peel_out`)   |       7 |            6 | 예        |
|              8 | 회전 (`turn`)       |       8 |            8 | 아니오    |
|              9 | 다른 달리기 (`run_alt`) |    9 |            8 | 아니오    |
|             10 | 포즈 (`pose`)       |      10 |            4 | 아니오    |
| **합계** |                           |         | **76** |           |

각 행의 프레임은 실제 이미지에서 왼쪽부터 오른쪽 순서로 코드에 직접 정의한다. 프레임 시간은 `idle=0.12`, `walk=0.08`, `run=0.07`, `roll=0.05`, `ball=0.05`, `dash=0.06`, `peel_out=0.05`, `turn=0.12`, `run_alt=0.10`, `pose=0.15`초다. 프레임 수, 행 순서, 좌표가 표와 다르면 표와 좌표 데이터를 함께 수정한다.

## 4. 사용자 흐름

1. 사용자가 `sonic_animation_viewer.py`를 실행한다.
2. 프로그램이 `sonic-sprite.png`를 읽고 재생 창을 연다.
3. 첫 번째 동작의 프레임이 정해진 시간 간격으로 화면에 표시된다.
4. 첫 번째 동작이 5회 재생되면 1초간 대기한다.
5. 같은 방식으로 다음 동작들을 순서대로 재생한다.
6. 마지막 동작까지 재생하면 첫 번째 동작부터 다시 시작한다.
7. 사용자가 창을 닫거나 `ESC`를 누르면 반복을 중단하고 프로그램을 종료한다.

## 5. 재생 규칙

1. 현재 동작의 프레임을 첫 프레임부터 마지막 프레임까지 순서대로 재생한다.
2. 프레임 전환은 동작별 `frame_time`과 실제 경과 시간을 기준으로 처리한다.
3. 하나의 동작이 마지막 프레임까지 재생되면 해당 동작의 반복 횟수를 1 증가시킨다.
4. 하나의 동작을 총 5회 반복할 때까지 첫 프레임부터 다시 재생한다.
5. 5회 반복이 끝나면 다음 동작으로 넘어가기 전에 1초간 대기한다.
6. 대기 시간이 끝나면 다음 동작의 첫 프레임부터 재생한다.
7. 마지막 동작까지 끝나면 동작 목록의 첫 동작으로 돌아간다.
8. 창 닫기 요청이나 `ESC` 입력이 들어오면 다음 프레임을 재생하지 않고 즉시 종료한다.

## 6. 기술 설계

- `pico2d.open_canvas(1200, 600)`으로 고정된 크기의 재생 창을 생성한다.
- `SPRITE_PATH`는 `__file__` 기준의 절대 경로로 만들어 실행 위치와 관계없이 이미지를 찾는다.
- `load_image()`로 `sonic-sprite.png`를 한 번만 읽고 프로그램 전체에서 공유한다.
- 매 프레임 `clear_canvas()`로 화면을 지우고 `clip_draw()`로 현재 프레임만 그린다.
- 각 프레임은 `(left, top, width, height, pivot_x, pivot_y)` 튜플로 관리한다. `pivot_x`는 프레임 왼쪽에서 몸 중심까지, `pivot_y`는 프레임 위쪽에서 발바닥까지의 원본 픽셀 거리다.
- 출력 위치는 `draw_x = x + (width / 2 - pivot_x) * SCALE`, `draw_y = FLOOR_Y + (pivot_y - height / 2) * SCALE`로 계산해 발바닥 높이를 `FLOOR_Y = 130`으로 고정한다.
- 이동 동작은 전체 5회 반복 시간 동안 `START_X = 180`에서 `END_X = 1020`까지 선형 이동한다. 제자리 동작은 `CENTER_X = 600`에 그린다.
- `get_time()`으로 동작 시작 시각과 프레임 변경 시각을 관리하고, 동작별 `frame_time`이 지나면 다음 프레임으로 전환한다.
- 상태는 `animation_index`, `frame_index`, `repeat_count`, `pause_started_at`, `started_at`, `frame_changed_at`으로 관리한다.
- 메인 루프에서는 입력 처리, 상태 업데이트, 화면 그리기를 일정한 순서로 실행한다.
- 프로그램 종료 시 `close_canvas()`를 호출하고 이미지와 창 자원을 정리한다.

## 7. 개발 단계

PRD 수정 커밋을 먼저 만든 뒤, 아래 25개 코드 단계를 각각 별도 커밋한다. 모든 커밋 메시지는 반드시 한글로 작성하며, 영어만 사용한 메시지는 인정하지 않는다. 각 단계는 실제 소스 변경과 실행 확인을 남긴다.

1. `sonic_animation_viewer.py` 파일 생성
2. 캔버스 크기와 기본 상수 정의
3. `__file__` 기준 스프라이트 경로 연결
4. `pico2d` 창 생성 및 닫기
5. 창 닫기와 `ESC` 이벤트 처리
6. 이미지 로드 및 기본 화면 갱신
7. 스프라이트 이미지 높이 상수와 로드 확인
8. 반복 횟수와 대기 시간 상수 정의
9. 바닥, 시작, 끝, 중앙 위치 상수 정의
10. 첫 번째 `idle` 프레임 좌표 등록
11. `top` 좌표를 `bottom` 좌표로 변환
12. 발 기준점을 적용한 첫 프레임 출력
13. `idle` 전체 프레임 목록 등록
14. `idle` 프레임 순서 재생
15. 동작별 프레임 시간 데이터 등록
16. 동작 인덱스와 프레임 인덱스 상태 관리
17. 실제 경과 시간 기반 프레임 전환
18. 동작별 5회 반복 계산
19. 반복 종료 후 1초 대기 상태
20. 대기 후 다음 동작 전환
21. 마지막 동작 후 첫 동작 순환
22. 이동 동작의 전체 반복 시간 계산
23. 시작점에서 도착점까지 선형 이동
24. 모든 동작 렌더링과 종료 자원 정리
25. 10종 76프레임, 프레임 시간, 기준점, 이동, 반복, 대기, 창 닫기, `ESC` 종료를 전체 검증

## 8. 완료 기준

- `sonic_animation_viewer.py`를 실행하면 오류 없이 뷰어 창이 열린다.
- 이미지 파일을 프로그램 시작 시 정상적으로 읽는다.
- 캔버스 크기는 `1200x600`이고, 원본 프레임은 `SCALE = 8`로 출력된다.
- 프레임이 지정된 순서와 시간 간격으로 재생된다.
- 10개 동작이 표에 적힌 이름과 순서로 재생되고, 프레임 수의 합이 76장이다.
- 모든 프레임의 top 좌표가 bottom 좌표로 올바르게 변환된다.
- 모든 프레임에 발 기준점이 적용되고, 발바닥 높이가 `FLOOR_Y = 130`으로 유지된다.
- 이동 동작은 5회 반복 동안 `START_X = 180`에서 `END_X = 1020`까지 이동한다.
- 제자리 동작은 `CENTER_X = 600`에 표시된다.
- 각 동작은 정확히 5회 재생된다.
- 각 동작이 끝난 뒤 다음 동작 전에 1초간 대기한다.
- 마지막 동작 이후 첫 동작으로 자연스럽게 이어진다.
- 창 닫기와 `ESC` 입력으로 프로그램을 정상 종료할 수 있다.
- PRD 커밋 이후 최소 25개의 단계별 코드 커밋이 남아 있고, 각 커밋은 한글 메시지와 실제 파일 변경을 포함한다.
